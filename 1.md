# Traffic Sign Detection & Classification Pipeline

Hệ thống thu thập, xử lý và phân loại biển báo giao thông tự động sử dụng YOLO và Computer Vision.

## 📋 Tính năng

- ✅ **Web Scraping**: Thu thập tự động 5000+ ảnh từ Google/Bing
- ✅ **Preprocessing**: Khử nhiễu, cân bằng sáng, tăng nét
- ✅ **Object Detection**: YOLO batch processing (10-20x faster)
- ✅ **Classification**: Phân loại 5 classes dựa trên màu sắc
- ✅ **Storage**: MinIO (ảnh) + MongoDB (metadata)
- ✅ **Visualization**: 10 biểu đồ phân tích chi tiết

## 🎯 Kết quả

- **Dataset**: 9,754 biển báo từ 3,220 ảnh
- **Classes**: Cấm, Nguy hiểm, Hiệu lệnh, Chỉ dẫn, Khác
- **Format**: YOLO labels (.txt)
- **Success rate**: 56.3% (ảnh có biển báo)

## 🚀 Cài đặt

### 1. Clone repository

```bash
git clone https://github.com/HoangKiew/traffic-sign-data-pipeline.git
cd traffic-sign-data-pipeline
```

### 2. Tạo virtual environment

```bash
# Windows
python -m venv venv
.\venv\Scripts\Activate.ps1

# Linux/Mac
python3 -m venv venv
source venv/bin/activate
```

### 3. Cài đặt dependencies (BẮT BUỘC: Cài thư viện Python, bao gồm minio)

```bash
pip install -r requirements.txt
```

### 4. Khởi động MinIO và MongoDB (Docker)

```bash
docker-compose up -d
```

Kiểm tra services:
```bash
docker ps
```

### 5. Download YOLO model (tự động khi chạy lần đầu)

Model YOLOv8n sẽ tự động download khi chạy script lần đầu.

## 🚦 Quy trình chạy pipeline từ đầu đến cuối

**Chạy từng bước thủ công hoặc tự động toàn bộ pipeline.**

### 1. Khởi động MinIO & MongoDB (chỉ cần 1 lần)
```bash
docker-compose up -d
```

### 2. Thu thập ảnh từ web (crawling)
```bash
python scripts/download_from_web.py
```
- Thu thập ảnh từ Internet, upload lên MinIO bucket `traffic-signs-raw`

### 3. Lọc nhanh ảnh rác, trùng, lỗi
```bash
python scripts/fast_filter.py
```
- Loại bỏ ảnh rác, trùng lặp, lỗi khỏi MinIO

### 4. Tiền xử lý, crop biển báo, lưu MinIO
```bash
python scripts/main.py
```
- Khử nhiễu, cân bằng sáng, tăng nét, crop biển báo, upload lên MinIO bucket `traffic-signs-processed` và `traffic-signs-crop-n`

### 5. Detection & Classification (YOLOv8n hoặc Dual YOLO)
```bash
# Chạy YOLOv8n (single model)
python processing_labeling/master_pipeline.py

# Hoặc chạy song song 2 model YOLO (dual YOLO, so sánh kết quả, đọc từ MinIO)
python processing_labeling/master_pipeline.py --dual-yolo --from-minio
```
- Nếu dùng `--dual-yolo --from-minio`: Chạy song song YOLOv8n và YOLOv8x, so sánh kết quả, sinh nhãn cho cả hai model, đọc ảnh trực tiếp từ MinIO.
- Nếu không truyền tham số: Chỉ chạy YOLOv8n, không so sánh, không đọc từ MinIO.

### 6. Gán nhãn, lưu metadata lên MongoDB, sinh biểu đồ so sánh
```bash
# Chạy YOLOv8n (single model)
python scripts/label_data.py --single-yolo

# Hoặc chạy dual YOLO (so sánh, sinh biểu đồ)
python scripts/label_data.py
```
- Nếu dùng `--single-yolo`: Chỉ gán nhãn bằng YOLOv8n, không so sánh với YOLOv8x, không sinh biểu đồ so sánh.
- Nếu không truyền tham số: Chạy dual YOLO, sinh nhãn, lưu metadata cho cả hai, vẽ biểu đồ so sánh.

### 7. Phân tích, visualize dữ liệu
```bash
python scripts/visualize_analytics.py
```
- Tạo 10 biểu đồ phân tích, lưu tại `outputs/analytics_charts/`

### 8. Tách train/val/test (nếu cần)
```bash
python scripts/data_split.py
```
- Chia dữ liệu train/val/test, sinh báo cáo phân phối class

### 9. Chuẩn bị dữ liệu crop cho classification (copy từ MinIO về local, theo class)
- Tải ảnh crop từ MinIO bucket `traffic-signs-crop-classified` về thư mục `outputs/crops/class_{id}/`

### 10. Train model phân loại (classification)
```bash
python scripts/train_classification.py
```
- Huấn luyện model classification, sinh file `model_classification.pt`

### 11. Kiểm tra kết quả phân loại với UI
```bash
streamlit run scripts/ui_predict.py
```
- Upload ảnh biển báo bất kỳ để kiểm tra kết quả phân loại

---

### 🚀 Chạy tự động toàn bộ pipeline (bước 2-7):

```bash
python scripts/unified_pipeline.py
```

  - `--skip-crawling`
  - `--skip-filtering`
